# 🌐 Lidia Kibret — Portfolio

My personal portfolio website, showcasing my projects, skills, competitive programming journey and data science work.

**🔗 Live site:** https://portfolio-five-pi-uz4mn2xkiy.vercel.app/

## ✨ Features
- Responsive design for mobile, tablet and desktop
- Dark / light theme toggle
- Live LeetCode and GitHub stats pulled from public APIs
- Sections: About, Skills, Projects, Competitive Programming, Data Science, Contact
- Smooth scrolling navigation and sticky header

## 🛠️ Built with
HTML5 · CSS3 · JavaScript · deployed on Vercel

## 🚀 Run locally
```bash
git clone https://github.com/Lidia-Kibret/Portfolio.git
cd Portfolio
python3 -m http.server 8000
```
Then open http://localhost:8000
